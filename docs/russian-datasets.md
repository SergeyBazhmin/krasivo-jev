# Русскоязычные датасеты

В реестре добавлено 20 русскоязычных наборов. Это подходящие источники, проверенные при расширении корпуса,
а не полный каталог всех существующих русских датасетов. Критерий отбора — ответ из предоставленного текста
и правил задачи, без внешних фактов; подробности — в [training-and-datasets.md](training-and-datasets.md).

Вопросы, инструкции и тексты категорий написаны по-русски. Все наборы имеют `type=choice`:
даже бинарные варианты читаются как «да» / «нет», тогда как `noul` у hosted baseline требует буквальных `yes` / `no`.
Идентификаторы бинарных вариантов остаются `yes` / `no`. Источники с загрузочными Python-скриптами
читаются из исходных ZIP/CSV/JSONL, без исполнения этих скриптов.

## Источники и задачи

Обозначения разделов: `tr` — train, `v` — validation, `te` — test.
Разделы указаны после конвертации, до создания недостающих разделов моделью.

## Фильтрация и смысл разметки

- Неразмеченные публичные тесты Russian SuperGLUE, RuCoLA, SberQuAD и MERA исключены.
  LiDiRus — размеченный диагностический test; строки с тегами внешнего знания исключены.
  RuBLiMP публикуется на Hub как `train`, но конвертер сохраняет его только как `test`.
- MuSeRC допускает несколько верных ответов. Каждый кандидат превращается в отдельную проверку да/нет.
  CEDR аналогично даёт пять независимых проверок эмоций; пустой список эмоций означает пять отрицательных ответов.
- У RuParaPhraser `-1` — корректная категория «не перефразировки». Три исходные категории сохранены;
  автоматически размеченный `plus.jsonl` не используется. Из train удаляются пары с любым заголовком из test.
- RuCoLA исключает `Hallucination`: такая ошибка может зависеть от отсутствующего оригинала перевода/пересказа.
- SberQuAD и MultiQ превращаются из извлечения ответа в выбор дословного фрагмента исходного текста.
  Правильный фрагмент выбирается по позиции размеченного ответа, а не по первому совпадению строки.
  Другие фрагменты с любым допустимым ответом не становятся
  отвлекающими вариантами. Строки без подтверждённого ответа или отвлекающих фрагментов исключаются.
  MultiQ получает оба исходных документа, но не скрытые `bridge_answers`.
- Арифметика, скобки и LCS проверяют исходный ответ вычислением. Числовые отвлекающие варианты заведомо отличаются
  от результата; верный ответ не обязан быть медианой вариантов. Для RuModAr семейство правил описано в `state`.
- Общие контексты новых наборов с несколькими исходными разделами сохраняются только в одном разделе:
  приоритет у test, затем validation, затем train. Несколько вопросов об одном контексте внутри раздела сохраняются.
  Симметричные пары RuParaPhraser и RUSSE канонизируются по порядку текстов.

Эти фильтры не доказывают достаточность контекста каждой строки и не устраняют все возможные пересечения
между разными источниками. Особенно полезна ручная проверка QA, NLI и субъективных языковых оценок.

## Что не включено

Russian SuperGLUE PARus и RWSD требуют неявного здравого смысла; RuCoS может требовать фактов вне отрывка.
У MERA исключены знания, экзаменационные факты, предпочтения и экспертные задачи с кодом;
`mathlogicqa/logic` содержит неуказанные сведения о животных и единицах измерения.
ruTiE смешивает внешние факты и иронию даже в арифметических диалогах.
Копия RCB в MERA не подключена, поскольку исходный RCB уже взят из Russian SuperGLUE.

Зеркала тех же токсичных комментариев и повторные смеси с SberQuAD не добавляются:
они увеличивают число источников без независимых данных и могут создавать утечку между разделами.
Расширение не включает большие неразмеченные корпуса, машинные инструкции и задачи без подходящей разметки.
[RuReviews](https://github.com/sismetanin/rureviews) исключён: его метки получены из скрытых оценок покупателей,
которые могут противоречить тексту отзыва. Нельзя считать такой рейтинг ответом, следующим из `state`.

## Лицензии

Лицензии исходных текстов продолжают действовать после конвертации.
[TextDetox](https://huggingface.co/datasets/textdetox/multilingual_toxicity_dataset) указывает **OpenRAIL++**.
[Карточка SberQuAD](https://huggingface.co/datasets/kuznetsoffandrey/sberquad) указывает лицензию **unknown**.
RuCoLA лицензирует код и метки под Apache 2.0, отдельно оговаривая права на исходные предложения.
Полные условия и происхождение текстов следует читать по ссылкам на источники перед распространением корпуса.

## Подготовка и проверка

При проверке 2026-10-05 получено 205 199 примеров после конвертации и фильтров.
С лимитом 10 000 на раздел сохранено **126 520 примеров в 20 наборах**.
Это размеры конкретной сборки; обновления источников могут менять количество строк.

```bash
uv run jev prepare cedr danetqa lidirus massive_intent_ru \
  mera_bps mera_lcs mera_mathlogicqa mera_multiq mera_rumodar mera_rumultiar mera_simplear \
  muserc rcb ru_paraphraser rublimp rucola russe russian_toxicity sberquad terra
```

По умолчанию сохраняется до 10 000 примеров каждого раздела в `data/<name>/`.
Для осмотра можно добавить `--max-samples 50 --output-dir /tmp/jev-russian`.
Модель создаёт недостающие validation/test по хэшу контекста; у LiDiRus и RuBLiMP обучающих строк нет.
Без явного списка модель использует все подготовленные наборы.

Проверка конвертеров включает реальные загрузки, схему с `float32`-метками, длину и нормировку распределений,
уникальность вариантов, воспроизводимость повторной конвертации, отсутствие общих контекстов между разделами
и чтение сохранённых данных через `datasets.load_from_disk`.

## Как искать следующие источники

Ищите русскую часть многоязычных наборов и авторские корпуса по задачам: NLI, paraphrase, intent,
sentiment, emotion, toxicity, acceptability, extractive QA и формальные reasoning-задачи.
Карточка источника и статья важнее названия: нужно проверить, откуда получены метки и какая информация
доступна модели. Например, намерение вопроса о факте можно классифицировать, не зная ответа на этот вопрос.

Перед добавлением загрузите реальные строки каждого раздела, включая отрицательные и неоднозначные классы.
Проверьте достаточность контекста, значение меток, отсутствие скрытого рейтинга/истории, публичные тесты,
лицензию и пересечения с уже зарегистрированными источниками. Для сборников проверяйте происхождение каждого
поднабора. Затем напишите конвертер и подготовьте по 50 примеров для ручного осмотра.
